Getting Started

DatasetDoctor is a local-first auditing tool for supervised tabular classification datasets.

1. Install

Download the Windows installer and run it. You do not need Python or PowerShell to use DatasetDoctor.

Download DatasetDoctor 1.8.7 Public Beta

2. Open a dataset

Launch DatasetDoctor from the desktop shortcut and select a supported local tabular dataset. Choose the target column before running target-dependent analyses.

3. Choose an audit mode

AUTO is the recommended default. DatasetDoctor may use bounded systematic samples for expensive analyses and reports the analysis scope in exported results.

4. Run analyses

Use Standard Audit for a broad first pass, or run modules individually such as Data Quality, Leakage & Association, Experiment Integrity, ML Reliability, Stress Test, Explainability, Repair Lab, or Synthetic Trust.

Long analyses run in the background. You can navigate to other pages while they continue. DatasetDoctor shows live progress and a completion notification.

5. Read findings conservatively

Scores and warnings are diagnostic evidence. Strong association alone does not prove leakage or causality. Sequential, grouped, and domain-specific datasets should be interpreted with their real experiment design in mind.

6. Export a report

After analysis, export the HTML report and reproducibility manifest for review or sharing.

Updates

Use Settings & Updates inside DatasetDoctor to check for a newer release. Update checks retrieve release metadata only. Dataset files are not uploaded.

Beta scope

Current validated scope is tabular supervised classification dataset and experiment auditing on Windows 10/11 64-bit.
