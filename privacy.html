Privacy

DatasetDoctor is designed as a local-first desktop application.

Dataset processing

Dataset files are processed on the user's local machine. DatasetDoctor does not upload raw datasets to a DatasetDoctor cloud service.

Telemetry

The 1.8.7 Public Beta does not include DatasetDoctor analytics telemetry.

Update checks

When the user checks for updates, DatasetDoctor retrieves release metadata from the public update feed. The update request is used to determine whether a newer release exists and does not upload the user's dataset.

Local files

Projects, settings, reports, caches, and related local application data are stored under the user's local DatasetDoctor application-data directory.

Exported reports

Reports are created locally. If a user chooses to share an exported report, that sharing occurs outside DatasetDoctor and is controlled by the user.

Beta notice

DatasetDoctor findings are diagnostic aids. They are not privacy certification, regulatory certification, or a guarantee that a dataset is safe to publish.
